# Click Fast!

Click Fast! est un jeu web de réflexes développé en HTML, CSS et JavaScript Vanilla.

## Objectif

Le joueur doit cliquer sur une cible qui change de position avant la fin du temps imparti.

## Fonctionnalités prévues

- Configuration du joueur
- Deux modes de jeu
- Trois difficultés
- Durée configurable
- Calcul du score et de la précision
- Records par configuration
- Historique des 20 dernières parties
- Sauvegarde avec localStorage

## Technologies

- HTML5
- CSS3
- JavaScript Vanilla
- localStorage

## État du projet

Projet en cours de développement.
